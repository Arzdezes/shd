Лабораторная работа 1: Программный RAID (mdadm)

Важно: Для выполнения команд с правами администратора мы будем использовать su -.
Переключитесь в режим root на обеих машинах.

1. Подготовка loop-устройств

Создадим файлы-образы (4 штуки по 100 МБ)

for i in {1..4}; do dd if=/dev/zero of=disk$i.img bs=1M count=100; done

Подключим все образы как loop-устройства

for i in {1..4}; do losetup -fP disk$i.img; done

Посмотрим, какие устройства получились

losetup -a                     # Список всех loop
lsblk                          # Древовидный вывод

2. Создание RAID-массивов

Синтаксис: mdadm --create /dev/md<N> --level=<L> --raid-devices=<X> <устройства>

RAID 0 (чередование) на двух дисках

mdadm --create /dev/md0 --level=0 --raid-devices=2 /dev/loop0 /dev/loop1

RAID 1 (зеркало) на двух дисках

mdadm --create /dev/md1 --level=1 --raid-devices=2 /dev/loop2 /dev/loop3

RAID 5 (чётность) на трёх дисках

mdadm --create /dev/md5 --level=5 --raid-devices=3 /dev/loop0 /dev/loop1 /dev/loop2

RAID 10 (комбинация) на четырёх дисках

mdadm --create /dev/md10 --level=10 --raid-devices=4 /dev/loop0 /dev/loop1 /dev/loop2 /dev/loop3

Полезные флаги:

  • --verbose или -v — подробный вывод
  • --force — принудительное создание (если ругается на суперблоки)

3. Наблюдение и мониторинг

Самый главный файл — статус RAID в реальном времени

cat /proc/mdstat

Слежение за процессом синхронизации (обновление каждую секунду)

watch -n 1 cat /proc/mdstat

Детальная информация о конкретном массиве

mdadm --detail /dev/md0

Краткая информация (аналог --detail, но короче)

mdadm --query /dev/md0

Проверка диска, входящего в массив

mdadm --examine /dev/loop0    # Информация о суперблоке на конкретном диске

4. Работа с массивом (файловая система)

Создадим файловую систему на RAID

mkfs.ext4 /dev/md0
mkfs.xfs /dev/md1             # Можно и XFS для разнообразия

Создадим точки монтирования

mkdir -p /mnt/raid{0,1,5}

Примонтируем

mount /dev/md0 /mnt/raid0
mount /dev/md1 /mnt/raid1

Проверим монтирование и размеры

df -h | grep md

5. Имитация поломок и восстановление

Работа с отдельными дисками:

Пометить диск как сбойный (FAIL)

mdadm /dev/md1 --fail /dev/loop2

Удалить сбойный диск из массива

mdadm /dev/md1 --remove /dev/loop2

Добавить новый диск (или пере-добавить старый)

mdadm /dev/md1 --add /dev/loop4     # Добавить новый диск
mdadm /dev/md1 --re-add /dev/loop2  # Попытаться вернуть старый

Временно отключть диск (имитация "шатания" контакта)

mdadm /dev/md1 --set-faulty /dev/loop2
mdadm /dev/md1 --remove /dev/loop2
# ... подождать ...
mdadm /dev/md1 --add /dev/loop2

Работа с массивом целиком:

Остановить массив

mdadm --stop /dev/md0

Запустить (собрать) существующий массив

mdadm --assemble /dev/md0 /dev/loop0 /dev/loop1

Автоматически собрать все массивы из конфига

mdadm --assemble --scan

Пересобрать массив вручную, игнорируя ошибки

mdadm --assemble --force /dev/md0 /dev/loop0 /dev/loop1

6. Полная зачистка (между лабораторными)

Отмонтировать всё

umount /mnt/raid*

Остановить все RAID массивы

mdadm --stop /dev/md*

Очистить суперблоки на дисках (важно!)

for i in {0..3}; do mdadm --zero-superblock /dev/loop$i; done

Отключить loop-устройства

for i in {0..3}; do losetup -d /dev/loop$i; done

Удалить файлы-образы (осторожно!)

rm -f disk*.img

Проверить, что всё чисто

losetup -a        # Должен быть пусто
cat /proc/mdstat  # Должен быть пусто

7. Часто возникающие проблемы и их решение

Проблема Команда
"Device or resource busy" при попытке остановить массив umount /dev/md0 сначала, потом mdadm --stop
"No superblock found" при добавлении диска Очистите суперблок: mdadm --zero-superblock /dev/loop0
Массив не собирается после перезагрузки Проверьте /etc/mdadm/mdadm.conf и сделайте update-initramfs -u
Хочу поменять уровень RAID Нельзя. Только создать новый массив и скопировать данные
Loop-устройства пропали после перезагрузки Это нормально.
Подключите заново: for i in {1..4}; do losetup -fP disk$i.img; done
Хочу посмотреть, что за массив был на диске mdadm --examine /dev/loop0

8. Пример полного цикла работы (RAID 1)

1. Подготовка

dd if=/dev/zero of=disk1.img bs=1M count=100
dd if=/dev/zero of=disk2.img bs=1M count=100
losetup -fP disk1.img
losetup -fP disk2.img

2. Создание RAID 1

mdadm --create /dev/md1 --level=1 --raid-devices=2 /dev/loop0 /dev/loop1

3. Форматирование и монтирование

mkfs.ext4 /dev/md1
mkdir /mnt/raid1
mount /dev/md1 /mnt/raid1

4. Работа с данными

echo "test" > /mnt/raid1/test.txt

5. Поломка

mdadm /dev/md1 --fail /dev/loop0
mdadm /dev/md1 --remove /dev/loop0

6. Починка (используем новый диск loop2)

losetup -fP disk3.img            # Создали новый образ
mdadm /dev/md1 --add /dev/loop2

7. Наблюдаем восстановление

watch cat /proc/mdstat
