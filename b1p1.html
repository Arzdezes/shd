Лабораторная работа 1: Разметка дисков.

Важно: Для выполнения команд с правами администратора мы будем использовать su -.
Переключитесь в режим root на обеих машинах.

Подготовка

Создаём файл-образ 100 МБ

dd if=/dev/zero of=~/disk.img bs=1M count=100
или 
truncate -s 100M disk.img

Привязываем к loop0

losetup /dev/loop0 ~/disk.img

Проверяем

lsblk /dev/loop0

Если нужно сбросить диск в «чистое» состояние:

 wipefs -a /dev/loop0

Далее мы будем знакомиться с утилитами разметки дисков.

cfdisk

Запуск:

cfdisk /dev/loop0

Просмотр:

сразу видно таблицу.

Создать раздел (MBR):

  • [New] → размер +50M → Primary → Enter
  • [Write] → yes → [Quit]

Создать раздел (GPT):

  • [New] → +50M
  • [Write] → yes

Удалить раздел:

  • Выбрать раздел → [Delete] → [Write]

Разметить чистый диск:

  • Если таблицы нет — cfdisk предложит выбрать dos/gpt.
  • Если есть — sudo cfdisk -z /dev/loop0 и выбрать dos/gpt.

fdisk

Просмотр:

fdisk -l /dev/loop0

Интерактивный режим:

fdisk /dev/loop0

Создать MBR-таблицу и раздел:

fdisk /dev/loop0

Command (m for help): o    # новая пустая MBR (dos)
Command (m for help): n    # новый раздел
Partition type: p (primary)
Partition number: 1
First sector: 2048
Last sector: +50M
Command (m for help): p    # посмотреть
Command (m for help): w    # записать

Удалить раздел:

fdisk /dev/loop0

Command: d
Partition number: 1
Command: w

Разметить диск с нуля (GPT):

fdisk /dev/loop0

Command: g    # создать новую GPT-таблицу

Command: n

...

Command: w

sfdisk

Просмотр:

sudo sfdisk -l /dev/loop0

Создать раздел одной командой (MBR):

echo 'start=2048, size=50M, type=83' | sudo sfdisk /dev/loop0

Создать два раздела (GPT):

echo 'label: gpt
start=2048, size=50M, type=0FC63DAF-8483-4772-8E79-3D69D8477DE4
start=50M, size=100M, type=0657FD6D-A4AB-43C4-84E5-0933C84B4F4F' | sfdisk /dev/loop0
(тип 0657... — Linux swap)

Удалить раздел 1:

sfdisk --delete /dev/loop0 1

Удалить все разделы (очистить таблицу):

echo 'label: dos' | sfdisk /dev/loop0   # или label: gpt

Сохранить разметку в файл и восстановить:

sfdisk -d /dev/loop0 > backup.txt
sfdisk /dev/loop0 < backup.txt

parted

Просмотр:

parted /dev/loop0 print

Создать MBR + раздел 50M:

parted /dev/loop0 mklabel msdos
parted /dev/loop0 mkpart primary 1MiB 50MiB

Создать GPT + раздел:

parted /dev/loop0 mklabel gpt
parted /dev/loop0 mkpart primary 1MiB 50MiB

Удалить раздел 1:

parted /dev/loop0 rm 1

Разметить с нуля в интерактиве:

parted /dev/loop0

(parted) mklabel gpt
(parted) mkpart primary 1MiB 50MiB
(parted) mkpart primary 50MiB 100MiB
(parted) print
(parted) quit

gdisk

Просмотр:

gdisk -l /dev/loop0

Создать GPT-таблицу и раздел:

gdisk /dev/loop0

o → Y        # новая таблица
n → 1 → Enter → +50M → 8300 → Enter
p            # просмотр
w → Y        # запись

Удалить раздел:

gdisk /dev/loop0

d → 1
w → Y

Разметить чистый диск:

Если GPT-таблицы нет — gdisk сам спросит, создать ли её.

Конвертировать MBR → GPT:

gdisk /dev/loop0

w → Y   # gdisk увидит MBR и предложит конвертацию
