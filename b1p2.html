Лабораторная работа 2: Создание файловых систем.

Важно: Для выполнения команд с правами администратора мы будем использовать su -.
Переключитесь в режим root на обеих машинах.

Подготовка

Используем вируальное устройство /dev/loop0 рамеченное ранее.

Считаем таблицу разделов /dev/loop0 и создим сопоставления устройств с обнаруженными сегментами разделов.

sudo kpartx -a /dev/loop0

Проверяем

ls /dev/mapper/loop0*

Мы увидим устройство /dev/mapper/loop0p1

Если нужно удалить сопоставление:

kpartx -d /dev/loop0

Далее мы познакомимся с утилитами создания наиболее популярных файловых систем.

FAT16 / FAT32

Для DOS/Windows совместимости используется mkfs.fat или mkfs.vfat (обычно одно и то же)

Создание FAT32 (автовыбор типа)

mkfs.vfat /dev/mapper/loop0p1

Явное указание FAT32 и метки

mkfs.fat -F 32 -n "USB_FLASH" /dev/mapper/loop0p1
Опция Описание
-F (размер FAT) Принудительно выбрать тип: 12, 16 или 32. Если не указать, программа выберет сама.
-n (метка) Задает метку тома (до 11 символов)
-S (размер сектора) Размер логического сектора (512, 1024, 2048, 4096). Будьте осторожны: >4096 нестандартно

NTFS (Windows-совместимость)

Для создания NTFS в Linux используется пакет ntfs-3g и команда mkfs.ntfs.

Создание

mkfs.ntfs /dev/mapper/loop0p1

С меткой диска 

mkfs.ntfs -L "WinDisk" /dev/mapper/loop0p1
Опция Описание
-L (метка) Задает метку тома.
-c (размер кластера) Задает размер кластера в байтах (512, 1024, 2048, 4096...). Рекомендуется 4096 для современных SSD/флешек.
-f (fast) / -Q (quick) Быстрое форматирование (только создание заголовков, без проверки плохих секторов).
-H (скрытые сектора) Задает количество скрытых секторов от начала диска до раздела. Обычно вычисляется автоматически, но может пригодиться для хакатона или специфичного софта.

ext4 / ext3 / ext2 (Linux-native)

Основная команда для Linux: mkfs.ext4 (также существуют mkfs.ext3 и mkfs.ext2). Это симлинки на программу mke2fs.

Создание ext4 на разделе

mkfs.ext4 /dev/mapper/loop0p1

Создание ext3 с меткой тома "MyDisk"

mkfs.ext3 -L MyDisk /dev/mapper/loop0p1
Опция Описание
-L (метка) Присваивает файловой системе метку (имя).
-b (размер блока) Задает размер блока в байтах (1024, 2048, 4096). Влияет на производительность при работе с большими/мелкими файлами.
-i (байт на inode) Задает соотношение байт/инод. Чем меньше число, тем больше инодов (файлов) можно создать. Полезно для директорий с миллионами маленьких файлов
-I (размер inode) Задает размер структуры inode (по умолчанию 128 или 256). Больший размер (256) нужен для поддержки расширенных атрибутов, но уменьшает полезное место
-m (резерв root) Задает процент места, резервируемого для root (по умолчанию 5%). Для данных можно смело ставить 0 или 1
