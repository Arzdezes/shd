Лабораторная работа 2: Шифрование блочных устройств (cryptsetup)

Важно: Для выполнения команд с правами администратора мы будем использовать su -.

1. Подготовка loop-устройства

Создадим файлы-образы (2 штуки по 100 МБ)

dd if=/dev/zero of=disk1.img bs=1M count=100
dd if=/dev/zero of=disk2.img bs=1M count=100

Подключим один образ как loop-устройство

losetup /dev/loop0 disk1.img

Посмотрим, какие устройства получились

losetup -a                # Список всех loop
lsblk                     # Древовидный вывод

2. Шифрование LUKS

Действие Команда / Ключи
Инициализация с параметрами шифрования cryptsetup luksFormat /dev/loop0
или
cryptsetup luksFormat -c aes-xts-plain64 -h sha256 -s 512 /dev/loop0
• -c — шифр (например, aes-xts-plain64, aes-cbc-essiv:sha256)
• -h — хэш-функция для генерации ключа (например, sha256, sha512)
• -s — размер мастер-ключа в битах (для XTS обычно 256 или 512)
Открытие (расшифровка) cryptsetup luksOpen /dev/loop0 my_encrypted_volume
Форматирование расшифрованного тома mkfs.ext4 /dev/mapper/my_encrypted_volume
Монтирование mount /dev/mapper/my_encrypted_volume /mnt/secret
Закрытие umount /mnt/secret
cryptsetup luksClose my_encrypted_volume
Просмотр информации (включая использованные параметры) cryptsetup luksDump /dev/loop0
Управление ключами cryptsetup luksAddKey /dev/loop0
cryptsetup luksRemoveKey /dev/loop0
cryptsetup luksChangeKey /dev/loop0

3. Комбинация RAID + LUKS

Вариант Последовательность команд
RAID поверх LUKS 1. Зашифровать диски:
cryptsetup luksFormat /dev/loop0 и /dev/loop1

2. Открыть:
cryptsetup luksOpen /dev/loop0 crypt-loop0 (и для loop1)

3. Создать RAID:
mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/mapper/crypt-loop0 /dev/mapper/crypt-loop1
LUKS поверх RAID 1. Создать RAID:
mdadm --create /dev/md0 --level=1 --raid-devices=2 /dev/loop0 /dev/loop1

2. Зашифровать массив:
cryptsetup luksFormat /dev/md0

3. Открыть:
cryptsetup luksOpen /dev/md0 crypt-raid

4. Создать ФС:
mkfs.ext4 /dev/mapper/crypt-raid
